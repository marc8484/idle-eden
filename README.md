# ⚔ Idle Eden

🎮 **[Play Now](https://marc8484.github.io/idle-eden/)**

A browser-based Realm vs Realm idle RPG inspired by classic fantasy MMORPGs.

Idle Eden combines idle progression, character development, crafting, boss encounters, and large-scale realm warfare into a persistent fantasy world where players compete for realm dominance.

---

## 🎮 Features

### Character Progression
- Multiple playable realms
- 37 unique classes
- Leveling and Realm Rank advancement
- Active class abilities with cooldowns
- Character statistics and progression tracking

### Combat
- Automated idle combat
- Active abilities
- Frontier enemies
- Named realm champions
- Boss encounters

### Realm Warfare
- Realm vs Realm battles
- Keep ownership and control
- Realm Points (RP)
- 8v8v8 arena combat
- Realm dominance bonuses

### Equipment & Loot
- Weapon, Helm, Chest, Ring, Cloak, and Boots slots
- Multiple rarity tiers:
  - Common
  - Uncommon
  - Rare
  - Epic
  - Legendary
  - Artifact
- Automatic loot generation

### Boss Content
- Frontier Boss: Pilzpower
- Guaranteed epic rewards
- Boss statistics and tracking

### Crafting
- Mining
- Foraging
- Herbalism
- Gemcrafting
- Potions and resource management

### Statistics
Track:
- Lifetime Kills
- Boss Kills
- PvP Kills
- Highest Damage
- Artifacts Found
- Gold Earned
- Realm Points Earned
- Hours Played

### Online Features
- Firebase Integration
- Cloud Saves
- Google Authentication
- Multiplayer expansion in development

### Discord Achievement Notifications (test only)
For local testing, open **Settings**, enter a Discord webhook URL, and use **Test Discord connection**. Newly unlocked achievements are posted while the page remains open. The test button sends a single connection-test message; no other gameplay events are sent.

This temporary integration sends directly from the browser. The webhook URL is held only in the current page and is not saved, but it can be inspected by browser users. Do not include a live webhook URL in source code or use this direct integration in a public release. A Firebase Cloud Function is planned for the secure production integration.
